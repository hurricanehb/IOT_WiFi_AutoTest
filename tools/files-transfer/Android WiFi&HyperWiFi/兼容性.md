# 兼容性
## 加密方式兼容性测试
### open网络接入测试
#### AP设置无线加密方式为Open
**属性：** 优先级：P0；摘要：Func_WlanAccess_Conn_Encrypt_Vali_052；类型：手工；标签：WiFi

**前置条件：**
1. AP配置为开放(Open)模式，无任何加密；
2. 无Portal认证；
3. DUT Wi-Fi功能正常。
**操作步骤：**
1. 打开DUT的Wi-Fi设置界面，扫描可用网络；
2. 找到目标Open网络SSID，直接点击连接（无需输入密码）；
3. 等待连接成功；
4. 连接成功后，打开浏览器访问 https://www.baidu.com。
**预期结果：**
1. DUT成功扫描到目标Open网络；
2. DUT成功发起连接请求，无需输入密码；
3. DUT成功连接，状态显示“已连接”，系统可能提示“此网络安全性较低”；
4. 能够正常打开https://www.baidu.com，页面加载完整，网络访问正常。

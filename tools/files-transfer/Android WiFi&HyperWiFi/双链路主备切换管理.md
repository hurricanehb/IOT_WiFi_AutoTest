# 功能
## 双链路切换管理
### 触发机制
#### 首次顺序连接WiFi、HyperWiFi网络后触发
**属性：** 优先级：P1；摘要：Func_PriBakLink_Trigger_ConStatChg_Vali_001；类型：；标签：HyperWiFi

**前置条件：**
1、测试环境：实验室屏蔽箱
2、陪测AP1、AP2、miniAP1、miniAP2可联网
**操作步骤：**
1、通过衰减器调节AP1_5G rssi为-73dBm/miniap1 rssi -70dBm
2、setting页面，手动顺序连接AP1_5G
3、再连接miniAP1，后台打印logcat | grep -iE “final score|setrole ifname：”，同步查看主备网络情况
**预期结果：**
3、setting-wlan列表查看HyperWiFi切到首行，后台打印wlan1 role: ROLE_CLIENT_PRIMARY，wlan0 role: ROLE_CLIENT_SECONDARY_LONG_LIVED；HyperWiFi网络为主网络

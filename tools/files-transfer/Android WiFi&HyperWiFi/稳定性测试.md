# 稳定性测试
## 强信号（>-60dBm）-稳定性测试
### 老化稳定性测试
#### 12小时5G WIFI大流量稳定性测试（WIFI为主网络）
**属性：** 优先级：P1；摘要：Stability_HRssi_AgeTest_001；类型：；标签：WiFi

**前置条件：**
1、拓扑：AC--AP/miniAP--STA

2、miniAPrssi控制在-45dBm左右
3、测试环境：实验室屏蔽箱
4、测试软件：Ixchariot或iperf3
**操作步骤：**
1、台式PC有线连接陪测AP，DUT无线连接陪测AP的5G
2、Ixchariot选择Throughput脚本，默认TCP，建立10pairs流，时间60S
3、DUT开启Endpoint程序，然后PC端开启打流，分别进行TX、RX吞吐量验证，并记录8小时流量数据
4、查看内存、CPU情况：adb shell cat /proc/meminfo 、adb shell cat /proc/cpuinfo
**预期结果：**
3、性能无减低，且无断流，与单WIFI时的表现相当
4、内存、CPU正常
